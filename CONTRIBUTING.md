# Contributing

This repository is a generated build. Each publication replaces the whole tree.

A pull request is a proposal. It is not merged into this tree. The maintainer
ports an accepted change into the source and closes the pull request with a
link to the release that contains it.

Open a bug report or a feature request with the issue forms. Say which release
you used. Only the latest release is supported.

Security and conduct reports are private. Use the Security tab, **Report a
vulnerability**. Do not open a public issue or a pull request for them. There
is no email address.
