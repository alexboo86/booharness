# Knowledge: catch-all floor of the harness home

What this page is: the map for every path of this repository that the harness domain does
not own. It starts empty on a new machine. Write facts here that a code search cannot
answer, each with its proof (`file:line`, a command, a URL). Session history, operator
decisions and open tails belong in memory (`memoryctl`), not on a page.

## What lives here

Nothing yet beyond the kit's own root files: `INSTALL.md` (how this machine was installed
and how to repair it), `KIT-MANIFEST.json` (the source commit and the sha256 of every
shipped file), `package.json` (harness scripts), `secrets.env.example` (names of optional keys).

The harness itself is mapped on [the harness page](../domain-harness/knowledge.md). That
page was written on the donor machine: its file and line references hold for this kit's
source commit, while its statements about a NAS, a Windows host, Gitea and production
servers describe the donor's environment, not this machine.
