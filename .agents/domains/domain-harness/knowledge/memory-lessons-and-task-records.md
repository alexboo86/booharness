## Memory lessons and task records

`scripts/memory/store.mjs` owns pure `selectLessonsForPath`/`matchLessonsForPath`. `scripts/memory/eval-delivery-set.mjs` freezes sampled commits with in-force lessons and file-anchored gold, following live active lineage heads and recording remaps/drops in its manifest. `scripts/memory/eval-delivery-replay.mjs` scores selection with each commit's routing map for recall, noise, stale, bytes and miss reason; commits lacking a map are not scored.

`scripts/memory/lesson-quality.mjs` checks only newly authored fields: code-point ceilings are title 120, rule 300, trigger/why/evidence 400. A nonempty `--long` reason permits excess and is stored as `- long:`; advisory targets are not refusal thresholds. Promotion, reanchor, normalization and retirement preserve unchanged historical fields. Decision appends have no same-topic judge: memoryd's `related_hint` lists similar live rules, and `--overturns` closes replacements. `scripts/memory/promote-lesson.mjs` refuses unresolved checkout anchors.

`scripts/memory/capture-gate.mjs` checks new writes before append. Anchors must exist in a current HEAD/local/origin ref tree and route to the domain. `anchorInRefs` tries HEAD first; literal anchors require the ref's own file content, and a holder after a HEAD-history deletion must contain the last deleting commit, including merge-only deletion. Glob anchors retain all matching refs; `ls-tree -z` results are cached by tree SHA. A new off-route capture adopts the sole explicit domain, normalizing a bare domain name; ambiguous or catchall-only routing refuses. Moves retain the refusal. `scripts/memory/sweep-anchors.mjs` and `scripts/check-domain-routing.mjs` share BRANCH (passes) and GONE (fails) classification. Capture does not compare same-file/glob lessons; supplied duplicate-check keys are stripped.

Successful captures are active without an inbox stage. CLI append uses the same gate; MCP append/local import refuse new lessons with capture instructions. `scripts/memory/lesson-duplicates.mjs` is read-only, pairing shared-anchor lessons by overlap and flagging polarity conflicts without a verdict. `scripts/memory/lesson-dedupe.mjs` combines legacy links, lexical pairs and same-domain dense neighbours from memoryd's read-only nearest-lessons endpoint. `scripts/memory/fit-lesson-dedupe.mjs` fits model-keyed thresholds in `scripts/memory/lesson-dedupe-fit.json`; missing fits or a model switch stop the run. Verdicts are recorded in `~/.local/state/lesson-dedupe/ledger.jsonl`.

`ops/orchestrator/src/memory-proposals.ts` preserves a superseded lesson's domain, anchor, status and globs, taking only the proposed trigger; retirement writes a lesson-shaped retired body. Failed pre-write reads are retryable refusals, failed writes uncertain. Lesson bodies require rule/why/evidence lines (`ops/orchestrator/src/report.ts`); definite refusals reach the lead untruncated. Titles/bodies use memoryctl file arguments to preserve multiline values under Windows Git Bash. `ops/orchestrator/src/lock.ts` handles Windows stop via the health-confirmed pid and matching dead-process lock; `ops/bootstrap/session-start.mjs` invokes the Git Bash provisioner without a shell.

`ops/orchestrator/src/handoff-draft.ts` drafts from stored reports without memory writes. Only reproduced findings become observed claims; a seat's reported checks enter the handoff draft as hypotheses, regardless of seat-written verification labels. `ops/orchestrator/src/report.ts` treats `reproduced` as evidence class: inferred findings are uncapped suggestions, never rechecks or capped notes. Orch delivers worker reports to the lead (`ops/orchestrator/src/context.ts`; `ops/orchestrator/src/seats-defs.ts`).

Append/handoff responses list at most 10 named open tasks with completion-command hints, without closing or refusing anything (`scripts/memory/store.mjs`, `scripts/memory/task-pure.mjs`). Tasks store a routing domain in `links.domain`, set/cleared through top-level domain; wholesale links updates preserve it, and domain-only updates preserve `updated_ts`. Task lists support compact fields, domain and closed-since filtering and report applied filters; duplicate refusals identify the existing task. `task-pure.mjs` owns helpers and `HttpError`, is imported by the store, and is included in the memory installer, NAS Dockerfile and installed-line-ending check.

`scripts/memory/eval-compile-delivery.mjs` compares seat/lead Edit/lead Read delivery before and after retirement, merge or page changes: lost lessons exit 1, unavailable Jev probes exit 2. Moved simulations write no memory: before uses live envelopes, after reloads active lessons and rebuilds with `selectLessonsForPath`. Supersedes keep links, same-domain moves use `reanchoredLinks`, refiles drop inherited globs. Undelivered moves exit 1, domain mismatches exit 2. `ops/routines/lesson-dedupe-weekly.md` preserves a retired anchor in the survivor's globs and compares delivery before retirement.
