## Portable kit build and verification

`ops/harness-kit/build-kit.mjs` (not in this kit) extracts a tracked revision using its include lists, overlay and neutralTextFiles swaps. Product-skill exclusions live in `ops/harness-kit/excluded-skills.json` (not in this kit), also used by board-picture generation. Private `ops/harness-kit/operator-patterns.json` (not in this kit) supplies leak regex/replacement/samples to leakGate and `ops/harness-kit/test-leak-gate.mjs` (not in this kit); neither inventory nor kit-builder directories ship. Leak scans read UTF-8 and UTF-16 LE/BE, and inventory entries need samples.

`check:harness-kit` runs mutant tests plus offline build --check through a private index/temporary stage, without network/archive. `scripts/check-commit.mjs` (not in this kit) runs that build against the proposed paths tree, not merely HEAD. Full builds select ref/output, never writing tracked directories. Guides, LICENSE, images and overlay come from the built revision; private leak/image/exclusion policies come from the executing checkout. Missing older-ref neutral-text targets skip; matching swaps otherwise throw on drift, including tester neutralization.

After the swaps and before the leak gate, one pass over shipped Markdown outside fences marks a code span, a command span or a relative link citing a file tracked at the ref but absent from the kit as `not in this kit`, and rewrites an `ops/harness-kit/overlay/<rest>` citation to the shipped `<rest>`; paths the kit `.gitignore` ignores stay unmarked. `ops/harness-kit/test-neutral-config.mjs` (not in this kit) scans the built kit for unmarked citations; `test-prefix.mjs` runs it on its default kit.

The root guides and SVGs render harness names; PNGs copy raw bytes (`ops/harness-kit/test-prefix.mjs` (not in this kit)). Raster magic bytes require exact approved hashes in `ops/harness-kit/image-policy.json` (not in this kit). `ops/harness-kit/make-board-pictures.mjs` (not in this kit) aliases identifying names and unshipped skills, then checks output text against its blocklist. MIT/Commons-Clause LICENSE and ops/claude-mods ship; `ops/bootstrap/permissions-target.mjs` preserves user plugin-directory entries. Kit config uses booharness while donor config uses booharness; doctor is `ops/bootstrap/doctor.mjs`.

`ops/harness-kit/INSTALL-PROMPT.md` (not in this kit) is the agent install interface, tested for ordered steps/verbs by `ops/harness-kit/test-install-prompt.mjs`. `ops/bootstrap/wizard-steps/families.mjs:probeFamilies` supplies family answers through the read-only runtime-path CLI. `scripts/lib/harness-config.mjs:wizardSpelling` supplies config spelling to every write verb: empty mcp.off disappears, empty skills.off stays and skills regroup by class. Default answers do not invent absent keys. The kit ships no bootstrap script; install is agent-led through the root guides.

KIT-MANIFEST.json stores kit identity, source commit, sorted path/byte/hash inventory excluding itself, and exclusion match counts. No timestamp, absolute path or hostname means deterministic builds. Builder --verify rejects missing/changed/extra files, symlinks, unsafe paths and malformed manifests. Offline --check omits package-lock generation. `ops/harness-kit/test-manifest.mjs` (not in this kit) independently inventories and mutates a kit. Builder import closure follows shipped production code; tests ship only by explicit inclusion, including config-writer and doctor tests that `test-prefix.mjs` runs inside a built kit. Prefix/config tests build HEAD plus changed sources; uncommitted new files require a snapshot checkout. SVG leak scanning does not decode entities.

Private leak replacements neutralize operator domains/MCP ids, including the shipped ON_DEMAND_OPERATOR value against an empty kit operator profile. Prefix tests derive forbidden names from that profile and copy executing-checkout policy into fixtures. Builder name rendering uses the shipped names.prefix and rejects unknown HARNESS tokens before leak checks. `ops/harness-kit/test-config-canonical.mjs` (not in this kit) pins canonical config output; builder validation precedes writing it. `test-prefix.mjs` pins default guide bytes.

`ops/memory-local/install.mjs` reads config before writes and refuses an existing com.<prefix>.memoryctl plist to prevent a second database writer; its own local.harness.memoryd label is fixed. Windows deployment uses `ops/bootstrap/win-task.mjs` for cmd/task installation and per-minute KeepAlive. Each forward gets a launcher/task using `scripts/lib/memory-forward.mjs`; reconciliation stops removed/changed ssh processes only by executable/argument match. Tunnels need a logged-on user. Task XML decoding recognizes UTF-16LE or the supported code page, refusing undecodable pages; drift compares only owned execution/trigger/logon/user fields because Scheduler rewrites other fields.

Public delivery is a Git repository; root guides point at clone/install, existing directories are not overwritten and cloned history skips bootstrap. Builder repo-url rendering precedes leak checks and accepts HTTPS or private-IPv4 HTTP with optional port; only exact guide occurrences of that URL gain the LAN-pattern exception. Templates store no account name; archives remain internal artifacts (`ops/harness-kit/test-prefix.mjs` (not in this kit)).

`ops/harness-kit/publish-kit.mjs` (not in this kit) refuses dirty sources, builds recorded HEAD through leak/manifest checks and copies only the gated kit to a temporary clone. Without push it stops at a diff stat; push is non-forced and requires commit-local author/email, not Git config changes. Source cleanliness/HEAD are rechecked and the clone removed. It does not create the destination repository; publication tools and private inventory do not ship.
