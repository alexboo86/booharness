## ASD-STE100 and language-mode behavior

`scripts/ste-check.mjs` exports standalone `check`, without network/model or daemon/hook/gate callers. It skips fences, backticks, double quotes, Cyrillic, URLs, paths, ids, numbers, identifiers, contractions and possessives. Classification order: `ops/orchestrator/ste/technical-names.json`, dictionary, two list shape patterns. Names match exact forms, -s/-es/-ies/-ed/-ing and irregulars. Results: rejected words/alternatives, unknowns, violations/100 words, technical-name share. Sentences above 25 words violate; above 20 and passive patterns are `maybe`; noun clusters above three words and paragraphs above six sentences report. `LIMITATIONS` accompanies results: no part-of-speech tagger.

`--corpus` summarizes recursive `.txt`/`.md` or JSONL `{kind, id, text}`, skipping/counting nonstring text. Violations keep exit status; usage/read errors exit 2. `scripts/ste-build-dictionary.mjs` builds untracked state `ste/dictionary.json` from allowlisted vocabulary JSONL (`docs/agent/harness-allowlist.md`). Symlink, git-worktree or outside-state output refuses; same-directory temporary/rename preserves other hard links. Coverage: `scripts/test-ste-check.mjs`. `ops/orchestrator/ste/rule.md` holds rules, technical-name definition and frequent rejected words/alternatives.

`language.json` in orch state holds `mode: off|flag|enforce`. `readLanguageMode` (`ops/orchestrator/src/language.ts`) reads on each call without throwing: missing means `off`, malformed JSON, unknown mode or other read errors mean `off` with a fault. `writeLanguageMode` uses a same-directory temporary file and rename. `node ops/orchestrator/src/main.ts language [off|flag|enforce]` writes a supplied mode and prints mode, file and fault; invalid arguments exit 2 without changing the file.

`ops/bootstrap/session-start.mjs` reads the switch each run. Lead sessions in `flag`/`enforce` receive `ops/orchestrator/ste/rule.md` beside operator rules, outside the capped diagnostics. Off, faults, missing rules or errors leave output unchanged; seats identified by `ORCH_SEAT_ID` or `SEAT_POLICY_ROLE` get no hook block. For seats, `steRuleBlock` reads on each call and returns rules in `flag`/`enforce`, otherwise null, never throwing. `SeatManager` (`ops/orchestrator/src/seats.ts`) asks once per turn. `ops/orchestrator/src/context.ts` appends the block after `closing()` only on the first message; `closing()` binds report free text to it on every turn while JSON keys, evidence, code, paths and commands stay verbatim. Null leaves messages unchanged; orch-authored steers remain plain English. Coverage: `scripts/test-orch-language-context.mjs`, `scripts/test-orch-language.mjs`, `scripts/test-session-start.mjs`.

`languageFor` (`ops/orchestrator/src/seats-digest.ts`) checks done reports' claims and `forLead`, not evidence or check lists, while mode is not off. `steSummary` (`ops/orchestrator/src/ste.ts`) returns judged words, violation rate, technical-name share, up to five rejected and five unknown words, alternatives and long-sentence count. `ops/orchestrator/src/digest-text.ts` renders the digest's `language` key. No mode adds a FLAG, repair turn or grade change. Off, missing/damaged dictionaries or any throw omit the key without failing digest consumers (`seat_wait`, CLI wait and board). A 128-entry oldest-first cache keys summaries by turn, mode and text. Coverage: `scripts/test-orch-language-check.mjs`.

At the MCP boundary, `languageOf` (`ops/orchestrator/src/http.ts`) adds `language` to `seat_prompt` and `chat_post` answers in non-off modes; clean text, missing dictionaries or throws leave answers unchanged. In `enforce`, `leadLanguageRefusal` refuses a brief with rejected/unknown words or long sentences before storing a turn or event. It names up to five words per kind and `main.ts language flag`; correction turns are checked too. Orch-composed rechecks, replacement-reviewer, lesson-repair and scout prompts enter through `SeatManager.prompt` and are not judged. Missing/damaged dictionaries never refuse; board operator posts receive no key. Coverage: `scripts/test-orch-language-prompt.mjs`.

Static switch text in `.agents/skills/orch-team/SKILL.md` and `ops/bootstrap/agent-instructions.md` is conditional, with no STE rules or word list; rules arrive only at switch readers, leaving no active rule text when off. CLAUDE.md and AGENTS.md do not name the switch.
