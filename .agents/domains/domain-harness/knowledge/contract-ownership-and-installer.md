## Contract, ownership and installer

`installPlugins` (`ops/bootstrap/install-harness.mjs`) manages no Claude plugin: it disables `caveman@caveman` in user settings and removes its marketplace/installed keys, preserving other entries. Invalid JSON stops with path and bytes unchanged. Caches remain; retirement runs only in the `plugins` step, not other checkouts' project settings. `session-start.mjs` expects no plugin. Project skills investigate-first, surgical-patch and verify-and-stop retain PROVENANCE files.

`parseArgs` (`ops/bootstrap/install-harness-args.mjs`) rejects unknown flags/steps, positionals, `--opt=value` and missing values with exit 2 before writes. Help exits 0 without steps. The codex step keeps one `booharness-codex-trust` block in `~/.codex/config.toml` for that run's roots, replacing previous roots. `replaceMarked` (`ops/bootstrap/marked-blocks.mjs`) absorbs same-root unmarked project tables, preserves other outside bytes, removes orphan END lines, and refuses unmatched BEGIN without writing. With multi-line strings it retains stray END and refuses. Coverage: `scripts/test-install-harness-safety.mjs`.

`acquireInstallLock` (`ops/bootstrap/install-lock.mjs`) holds `<home>/.harness-install.lock` (pid/start time) across `main()`, independent of prefix/config. Live pids refuse without writes; dead/unparseable locks use hard-link publication and a stale-file-keyed reaper claim. Success/throw/exit releases only this run's lock; killed runs leave reclaimable locks. Usage-only and skipped skills/code-intel runs take no lock; others do. Reused pids refuse until exit; start time is not compared. Coverage: `scripts/test-install-lock.mjs`.

`ops/bootstrap/owned-entries.mjs` stores `{<real target path>: {<list name>: [entries]}}`. `mergeKeep` returns canon first plus unowned present entries; without a record, canon-equal entries are owned. `writeOwned` publishes old-owned plus new-canon, calls the synchronous target writer, then publishes new-canon; failed writes retain an ownership superset. Manifest temporary/rename uses mode 0600. Invalid/unreadable manifests stop writes; absent means no record. Realpath/nearest-parent keys unify symlinks and Windows case. Callers lock and validate targets first. Coverage: `scripts/test-install-owned-entries.mjs`.

`install.userEntries` selects `replace` (default/tracked) or `keep`. `installPermissions` calls `writePermissionSettings` (`ops/bootstrap/permissions-target.mjs`): missing/invalid config stops before writes. Replace sets canon allow/deny, preserving other keys; absent settings mean empty. Keep requires object settings/permissions and string-array allow/deny; invalid targets stop unchanged. `writeOwned` uses `<home>/.local/state/<prefix>/installed-entries.json` to preserve user rules and retire dropped canon. Deny wins. Coverage: `scripts/test-install-permissions-keep.mjs`.

`installMcp` requires valid config even with `--secrets-file`. `buildJsonConfig`/`publishConfigs` (`ops/bootstrap/mcp-config-target.mjs`) plan/publish JSON batches. Replace uses non-operator `preserve_existing` ids plus selected servers. Keep uses shared manifest `mcpServers`: user values stay, selected ids render anew, deselected owned ids go. Retired and non-profile operator ids go even without records. Invalid JSON/object shapes stop with path, without secret-bearing parser text. Realpath writes preserve symlinks/unify case. Commit failure restores published configs and prior manifest bytes, removing new manifests. TOML retains explicit selected/operator/retired lists. Coverage: `scripts/test-install-mcp-keep.mjs`.

`ops/bootstrap/mcp-servers.json` retires `operator-trade`; it is absent from the operator list, so all runtime configs remove it even with `--operator-profile` (`scripts/test-mcp-ssot-render.mjs`). The lead row of `ops/orchestrator/mcp-by-role.json` retains `brightdata-web`.

`installRtkExcludes` (`ops/bootstrap/rtk-config-target.mjs`), wired by the `rtk-excludes` installer step, owns `[hooks].exclude_commands` through the shared manifest. Config locations: macOS `~/Library/Application Support/rtk/config.toml`, Windows `%APPDATA%\rtk\config.toml`, Linux absolute `$XDG_CONFIG_HOME` or `~/.config/rtk/config.toml`. Entries match word-boundary prefixes; leading `^` is raw regex. Canon includes `git log` and `^git\s+(?:-{1,2}[A-Za-z][A-Za-z0-9-]*(?:[= ]\S+)?[ ]+)*log(?:[ ]|$)` for option-prefixed log commands, not status/stash log. `ops/bootstrap/rtk-rewrite-lib.mjs` independently refuses these via `gitSubcommandOf`; config covers rtk's own Claude hook and Pi rewrite routes.

The rtk writer recognizes quoted/spaced TOML tables/keys and CRLF, preserves raw entry slices and interior comments, and validates its render with `verifyRendered`. Before append it scans the whole file for dotted/inline hooks definitions, escaped headers/keys and subtables. Unmodelled files (including array tables, duplicate tables/keys) remain byte-identical with a warning/manual step. Coverage: `scripts/test-install-rtk-excludes.mjs`, validating renders with tomllib.

`ops/harness-kit/build-kit.mjs` sets public kit `install.userEntries: keep`; repository config stays replace (`ops/harness-kit/test-prefix.mjs`).

Hook ownership is command-form-based. `harnessHookScript` (`ops/bootstrap/install-harness.mjs`) accepts `node "<checkout>/ops/bootstrap/<script>"` with at most one of `claude`, `codex`, `grok`, `kimi`, `precompact`, `deliver`; `rtk hook claude` is owned by equality. Composed commands (operators, redirects, dollar/backtick/backslash/newline), unquoted paths and Windows backslash paths are not owned. Sweeps remove owned commands only, preserve siblings and remove only entries they emptied. `ensureHook` repoints old-checkout hooks and leaves one carrying hook per event; unowned commands stay beside the added harness entry. Shared entries retain matchers while the harness command moves to its own entry. `installLeadHooks` (`ops/bootstrap/lead-hooks.mjs`) applies `asyncRewake`/`timeout` only to the owned Stop watcher. `stripRetiredLeadHooks` removes nothing in keep; replace removes exact retired Paseo lines, plain `paseo hooks ...` and commands whose program is in `/.orca/agent-hooks/`, not compositions or later-argument paths. Interpreter flags before orca paths keep the command.

`readHarnessConfig` (`scripts/lib/harness-config.mjs`) accepts optional `install.userEntries`, `memory.embed.url`, `families.enabled`; the tracked config omits the latter two. Unknown keys are refused by older readers. `embedUrlRefusal` requires http/https without userinfo/query/fragment. `ops/bootstrap/install-memory.mjs` precedence is `--embed-url`, saved `local-service.json` option, config key, matching model precedence. The kit overlay `ops/harness-kit/overlay/ops/memory-local/install.mjs` uses `http://127.0.0.1:11434` only without saved option or key.

`families.enabled` is a frozen, nonempty, duplicate-free array of known `HARNESS_FAMILIES`, equal to provider `FAMILIES` (`ops/orchestrator/src/providers/types.ts`). `FAMILY_CLI_NAMES` (`ops/bootstrap/resolve-runtime-path.mjs`) maps glm to claude, qwen/mimo to no CLI. `resolveProviders`, `activeTools` (`ops/update-tools.mjs`) and `ops/setup-machine.sh` through `--clis` require/update/check only enabled families' CLIs; absent means Claude Code only (`REQUIRED_PROVIDERS`, `ops/bootstrap/resolve-runtime-path.mjs`). `canonicalSearchDirs` preserves four vendor-bin directories and order.
