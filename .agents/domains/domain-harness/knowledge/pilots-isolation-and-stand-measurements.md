## Pilots, isolation and stand measurements

`ops/ab-stand/run.mjs` defines the task/arm/family matrix and RTK-only baseline. Every cell runs memory off; no-lessons suppresses only orch injection, records stand-no-lessons and creates no lesson_deliveries. The lesson-usefulness pilot replays historical coder bases/verbatim briefs on lesson fixtures; `ops/ab-stand/lesson-probe.mjs` scores acceptance plus absence of reviewer-reproduced mistakes. Fixtures start at seat base, not fix parent. `ops/ab-stand/report.mjs` pairs by cohort/family/task/model. Hashline pilots use declared arm order, pairing against the first arm rather than assuming base, and refuse reps above 3.

Arm hints in `ops/ab-stand/arms.mjs` enter frozen briefs and cell keys only when present. Caps/timeouts also key cells, avoiding mixed resumes. Transcript evidence counts arm gateway calls, or null without MCP requirements. Wait uses turn limit plus queue margin; wait exhaustion/fetch failure is retryable infrastructure with null score, not scored failure. Capped cells are finished; closing failures preserve worktrees.

`ops/ab-stand/obs-mask.mjs` is the Pi context extension: older tool observations beyond the newest 10 are masked while the first stays; a monotonic frontier advances in batches of 5 per session without changing history.

`ops/orchestrator/src/stand.ts` resolves allowlisted standArm ids into isolated profiles/environment; absence leaves stock sessions/context untouched. `ops/ab-stand/install.mjs` installs under ~/.local/state/orch/ab-stand/arms with separate Pi package, HOME, sessions/caches and copied RTK. `ops/ab-stand/auth.mjs` refreshes auth snapshots per cell with refresh grants blanked, preventing live-grant rotation; mid-cell-expiring tokens skip, OAuth/capacity failures retry. Serena uses a pinned commit. `ops/ab-stand/smoke.mjs` exercises isolated tools/RTK. OCI requires stand-local Ollama/index preparation in both scout and coder worktrees.

Quota is read before cells and after provisioning; unreadable/stale/ahead-of-pace/throttled quotas fail closed. The explicit Kimi pace exception retains throttle/long-window/cap guards. Two runs per family per invocation are allowed before resume. Stand-only token_cap counts cumulative input/output/cacheRead, default 400000 with validated override, and one response may overshoot (`ops/orchestrator/src/seats-prompt.ts`). Reports aggregate done rows within cohorts, with cache-write, hit share and Pi catalog billing; incomplete usage or zero-cost token runs produce unknown billing, never zero. Installation/dry-run does not reload the live daemon (`ops/ab-stand/README.md`).

`ops/ab-stand/metrics.mjs` reads live seats for pooled cache hit share and token distributions by family/role, sharing usageParts with `ops/orchestrator/src/pick-stats.ts`; missing usage is named, not zero. `ops/ab-stand/edit-metrics.mjs` reads Pi JSONL for failures, reread loops and first-edit success by arm/family/role. Success needs a present non-error result; missing results remain unknown in the denominator and undo never decides it. Hashline errors classify as other. Remote/native-Claude coverage gaps are named within the requested window.
