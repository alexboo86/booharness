## Claude Code mods

`ops/claude-mods/` holds `.claude-plugin/plugin.json`, `hooks/hooks.json`, hook modules and tests. Engine-generated `.claude-plugin/types/` is gitignored; fresh checkouts cannot typecheck without a copy. Mod checks: `claude plugin validate .`, `npx tsc -p . --noEmit`, `claude plugin test .`. `CLAUDE_CODE_PLUGIN_DIRS` in `~/.claude/settings.json` loads mods into lead sessions; native claude/glm worker seats clear it in both the spawn env and `--settings` env (task 3200), so no mod reaches a seat; dev-mods prompt for hot reload, and double-listing loads twice.

`lead-wake/hooks/register.ts` starts `startWakeHold` (`hooks/wake.ts`) on `session.start` and calls `turnStarted`/`turnEnded` on `turn.start`/`turn.complete` (task 2589). While no turn runs, the hold keeps `GET http://127.0.0.1:7760/chat/wake?session=<id>&holder=mod` open; a released batch is submitted with `$.prompt.submit`, then receipted by `POST /chat/delivered` with Origin and `X-Orch-Chat` (at-least-once: a lost receipt re-offers the post). A network error or 5xx retries in 5 s; any other non-200 (400: no live chat binding) backs off 5 min; a superseded answer stops the old hold after a module reload. The daemon ranks the mod hold above a late Stop watcher (`ops/bootstrap/lead-chat-watch.mjs`, 7100 s) in the `holder=mod` branch of `/chat/wake` (`ops/orchestrator/src/http.ts`). The orch-board pane mod was removed (operator #21159); the operator views the web board at `http://127.0.0.1:7760/`.

`handover/hooks/register.ts` registers `mcp__handover__run {text, clear}`. True keeps text in a module variable and runs `/clear` after the turn; `session.end` with reason `clear` submits it as the cleared session's first prompt. Refused clear drops text; false submits a new prompt in the same session. Without the tool, the relay session remains the fallback.

Vendored mods carry `NOTICE` and `VENDOR.json` (source, SHA, license, per-file SHA-256); `review_plan` excludes hash-matching files from reviewer count. Modified files are omitted from `files` and named in NOTICE. `collision-guard` keeps per-chat ledgers in `~/.claude/mods-data/collision-guard/`, warning on shared edits via read-only `git ls-files`. `delay-no-more` restores deferred tools in `tool.describe`, writing nothing. `secrets-veil` masks 21 named secret variables and denies calls if masking fails; it emits no start notice. None of these three makes its own network calls. `ops/harness-kit/test-prefix.mjs` (not in this kit) collects all mod files; the installer registers only `CLAUDE_MOD_NAMES` in `ops/bootstrap/permissions-target.mjs`.

`secrets-veil` masks only named values in `base64`/`data` with PNG/JPEG/GIF/WEBP/PDF signatures (`isEncodedMedia`); plain-text base64 is fully masked.
