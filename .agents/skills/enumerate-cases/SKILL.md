# Enumerate cases

Widen before choosing. One answer reached quickly is a sample, not a decision.

- List the cases the answer must survive: empty, single, maximum, concurrent, repeated, dependency failure.
- Give at least two shapes of answer and say what each costs.
- Name what would make each shape wrong, and how you would find that out.
- Keep a disagreement rather than averaging it away; the losing reason is data.
- Decide only when a case decides it; otherwise say what stays open.

Report the shapes, the cases, and the one you chose with its reason.
