# Все правила корпуса, по префиксу

Полный перечень апстримного корпуса — 265 правил. Он существует ради полноты и
ради того, чтобы перекрёстные ссылки внутри правил вели в живые файлы.

**Читать отсюда не надо.** Точка входа — таблица в [../SKILL.md](../SKILL.md): она
ведёт к тридцати правилам асинхронности и конкурентности, ради которых корпус и взят.
Сюда приходят, когда в той таблице ничего не подошло, а вопрос всё равно про Rust.
